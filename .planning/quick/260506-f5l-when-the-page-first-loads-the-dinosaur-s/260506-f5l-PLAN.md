<objective>
Add a "Press Space to Start" idle gate so the game does not begin automatically on page load. The dino is rendered standing at ground position; nothing else moves, spawns, or scores until the player presses Space or ArrowUp. After a game-over, the existing 'r' restart returns to this same idle state.

Purpose: Match the real Chrome dinosaur game's UX — the dino waits for the player. Without this gate, the player loads the page mid-run and either dies immediately to an oncoming cactus or just sees the dino sprinting before they're ready.

Output: A modified `dino.js` with a `gameStarted` flag that gates physics, scoring, spawning, and renders a centered start prompt while idle. No new files; no HTML/CSS changes.
</objective>
