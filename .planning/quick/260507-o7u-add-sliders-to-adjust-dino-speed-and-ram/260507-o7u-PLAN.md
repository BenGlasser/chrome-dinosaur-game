**Edit 2 — Compute `effectiveVelocityX` once per frame at the top of `update()`'s active section.** Insert it AFTER the `if (!gameStarted) { ... return; }` block (i.e. immediately after line 184 and before the `//track` comment on line 186):

```js
    //per-frame effective scroll velocity — slider speed is the base magnitude; slider ramp scales with score
    //formula locked: effective = -(baseSpeed + rampRate * (score / 1000))
    //defaults speed=4, ramp=0 reproduce the legacy velocityX = -4
    let baseSpeed = parseFloat(speedSlider.value);
    let rampRate  = parseFloat(rampSlider.value);

```

If JS scope concerns arise, promote the four slider DOM references to module-scope `let`s declared near the other globals (around line 73) and assign them inside `window.onload` — this is the safer pattern and matches how `board`, `context`, `track1`, `track2` are already handled.
