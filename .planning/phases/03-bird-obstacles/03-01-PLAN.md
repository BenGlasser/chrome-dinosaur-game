<objective>
Establish the bird entity model and spawning machinery in dino.js. After this plan ships, a player loading the game in a browser sees birds materialize at the right edge at three discrete heights (`birdLowY = 110`, `birdMidY = 156`, `birdHighY = 50`) and scroll left across the canvas at the same speed as cacti — but birds do NOT animate (single static frame `bird1Img`) and birds do NOT yet trigger game-over on contact (collision wiring is plan 03-02). This intermediate state is intentionally observable so the user can play-verify spawn cadence and height variety BEFORE animation and collision are layered on.

Purpose: De-risk Phase 3 by separating spawn/scroll (mechanical and visually verifiable on its own) from animation/collision (behavioral). Splitting the work gives a checkpoint where the user can see birds move correctly at all three heights without animation noise or sudden game-overs while iterating.

Output: `dino.js` extended with the `//bird` globals block, two sprite preloads, a 1500ms spawn timer, a `placeBird()` function with the probability-band height picker, and a bird update/scroll/draw loop in `update()`. Birds satisfy the entity-shape contract `{img, x, y, width, height}` so plan 03-02 can wire `detectCollision(dino, bird)` unchanged.

Requirements addressed:
- **BIRD-01** — Birds spawn periodically alongside cacti and scroll left at game speed (D-02, D-04, D-13).
- **BIRD-03** — Three discrete heights are present (`birdLowY=110` / `birdMidY=156` / `birdHighY=50`), satisfying "multiple discrete heights … at minimum a low requiring duck and a high requiring jump-or-stand" once collision is wired in 03-02 (D-06).

```js
function placeBird() {
    if (gameOver) {
        return;
    }

    //place bird
    let bird = {
        img : bird1Img,    //initial frame; the update() draw loop re-picks per-frame from frameCount (added in plan 03-02)
        x : cactusX,       //reuse cactusX = 700 — both obstacle types enter from the right edge per D-04
        y : 0,             //assigned below by the height roll
        width : birdWidth,
        height: birdHeight
    }

    let placeBirdChance = Math.random(); //0 - 0.9999...

    if (placeBirdChance > .80) { //20% no bird — breathing room when a cactus stack would be unfair
        return;
    }
    else if (placeBirdChance > .55) { //25% high (y=birdHighY) — punishes reflexive jumping
        bird.y = birdHighY;
        birdArray.push(bird);
    }
    else if (placeBirdChance > .30) { //25% mid (y=birdMidY) — must jump
        bird.y = birdMidY;
        birdArray.push(bird);
    }
    else { //30% low (y=birdLowY) — must duck (depends on Phase 2 D-14 hitbox shrink)
        bird.y = birdLowY;
        birdArray.push(bird);
    }

    if (birdArray.length > 5) {
        birdArray.shift(); //count-based prune; safe at current scroll speed, see CONCERNS.md §"Latent Bugs" #1
    }
}
```
