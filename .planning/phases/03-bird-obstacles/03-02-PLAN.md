1. Inside the bird loop in `update()`, replace `bird.img` in the `drawImage` call with a per-frame flap picker (`Math.floor(frameCount / 12) % 2`) that swaps between `bird1Img` and `bird2Img`.

3. Inside `resetGame()`, add a single line `birdArray = [];` adjacent to the existing `cactusArray = [];` line.

Requirements addressed:
- **BIRD-02** — Each spawned bird animates with alternating `bird1.png` / `bird2.png` frames at a flap rate distinct from the dino's run/duck rate. Implemented with `Math.floor(frameCount / 12) % 2` (D-10/D-12), which is exactly half the dino's `frameCount / 6` rate (Phase 2 D-10).
- **BIRD-04** — Bird-vs-dino collision triggers the same game-over path as cactus collision. Implemented by mirroring the cactus collision branch verbatim (D-13/D-15) and extending the canonical reset list with `birdArray = []` (D-17).

This plan also empirically validates **BIRD-03** end-to-end (heights are now lethally distinct: low requires duck, mid requires jump, high requires standing/ducking). Plan 03-01 established the heights existed; this plan makes the height-strategy mapping observable through play.
